# Портфолио веб-верстальщика

Одностраничное портфолио на основе проектов из папки `frilans`.

## Содержимое

- **Евклид** — адаптивный лендинг, кроссбраузерная вёрстка
- **Курсы 3D-моделирования** — лендинг на Bootstrap Grid
- **Кредитный калькулятор** — веб-приложение с JavaScript и Chart.js
- **Число Миссии** — нумерологический калькулятор на JavaScript
- **Летописный свод России** — многостраничный информационный сайт

## Локальный запуск

```bash
cd portfolio
npx serve .
```

Откройте `http://localhost:3000` в браузере.

> Скриншоты лежат в `portfolio/img/` — портфолио самодостаточно и деплоится без соседних папок.

## Публикация на GitHub Pages

1. Создайте репозиторий (например, `portfolio`) и загрузите папку `portfolio` вместе с проектами или скопируйте нужные изображения в `portfolio/img/`.
2. **Settings → Pages → Source**: Deploy from branch → `main` → `/ (root)` или `/portfolio`.
3. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.
